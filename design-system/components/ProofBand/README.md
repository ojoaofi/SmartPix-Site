# ProofBand

Faixa lima de prova social, logo abaixo da abertura: quatro números ou fatos curtos, cada um com o traço do X.

Uma `<ul class="sp-proof">` com quatro `<li>`, cada um com `<b>` (o número ou fato, até ~14 caracteres) e `<span>` (a explicação em uma linha).

- É a única faixa inteira em `lime` da página.
- Só dados confirmados pela empresa: nota do Google, capacidade real, estrutura própria.
- Em telas menores que 860 px vira 2 × 2.

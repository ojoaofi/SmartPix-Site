# Chip

Pílula de escolha para respostas curtas: prazo, instalação, perfil e origem do contato.

`sp-chips` com `<label class="sp-chip">`, um `<input type="radio">` e o `<span>` com o texto (até três palavras). O escolhido fica `ink` com texto `surface`.

- Use para perguntas de 2 a 5 respostas; acima disso, use `sp-card`.
- Todo chip tem 44 px de altura.

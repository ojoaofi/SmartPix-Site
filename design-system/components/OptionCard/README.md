# OptionCard

Cartão de escolha do configurador de orçamento: ícone de traço, nome do produto e uma linha de apoio.

Grade `sp-cards` de `<label class="sp-card">` com `<input type="radio">` e um `<span>` com `<svg>` (ícone 32 × 32 de traço), `<b>` (produto) e `<small>` (o diferencial em poucas palavras).

- Use dentro de `surface-alt`; o selecionado ganha borda `ink` e fundo `lime-soft`.
- Um grupo por pergunta. Para escolha múltipla, troque `radio` por `checkbox`.

# Kicker

Rótulo em minúsculas espaçadas, com o traço do X, que abre um título como o "impressão digital" do selo.

Coloque `<p class="sp-kicker">` logo antes de um título `sp-h`. O texto é sempre minúsculo, curto, com itens separados por " · ".

- Sobre `surface`, a cor é `lime-ink`; dentro de `sp-stage`, `lime`.
- Destaque de palavra no título: `sp-lime` sobre stage, `sp-mark` (marca-texto) sobre fundo claro. Um por título.
- Não use outro marcador no lugar do traço.

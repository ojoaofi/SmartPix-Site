# Button

Botões em pílula, sempre em par: o cheio em lime para a ação de compra e o contornado para quem ainda pesquisa.

Use `sp-btn sp-btn--fill` para a ação que a página quer (montar orçamento, orçar um produto) e `sp-btn sp-btn--line` ao lado para a alternativa ("Ver projetos").

- Um botão cheio por bloco. O texto começa com verbo.
- Dentro de `sp-stage`, o contornado vira lime automaticamente.
- `sp-btn--sm` (44 px) nos blocos 2 × 2; `sp-btn--block` (56 px, largura total) no envio do pedido.
- O consumidor fornece o elemento (`<a>` ou `<button>`) e o texto; ícone opcional como `<svg>` de 20 px antes do texto.
- Não use lime como botão sobre `lime`, nem botão branco.

# Notice

Aviso curto dentro do resumo do pedido: confirmação em lime, prazo em âmbar e erro em vermelho.

`<p class="sp-notice">` para uma boa notícia sobre o pedido, `sp-notice--warn` para atenção (prazo curto) e `<p class="sp-error">` (com `role="alert"`) para o que falta no formulário.

- Uma frase, dizendo o que fazer.
- Nunca prometa prazo ou preço que a empresa não confirmou.

# Tile

Bloco 2 × 2 de 580 px no estilo Apple: foto em tela cheia, título, uma frase e o par de botões.

`<article class="sp-tile">` com `<img>` (cobre o bloco), `.sp-tile-copy` (título `sp-h--section`, uma frase `sp-lead`, botões `sp-btn--sm`) e `<span class="sp-tag">` dizendo "Foto real" ou "Ilustração IA".

- Dois por linha no computador, com `space-3` entre eles; um por linha abaixo de 734 px (520 px de altura).
- Cantos retos. O degradê de `stage` no topo garante a leitura do texto.
- Texto alternativo descreve o trabalho; em ilustração, começa por "Ilustração gerada por IA:".

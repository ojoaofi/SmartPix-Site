# SegmentCard

Cartão de perfil do comprador (agência, montadora, varejo, empresa) que leva ao orçamento já com o perfil marcado.

`<button class="sp-seg">` com a caixa de ícone `sp-ic` (ícone lime sobre stage), `<b>` (o perfil), `<span>` (o que ele compra) e `<em>` (a ação, terminando em "›").

- Quatro lado a lado no computador, dois no tablet, um no celular.
- O consumidor liga o clique ao formulário de orçamento.
